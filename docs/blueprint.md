# **App Name**: Galapagos DataLens

## Core Features:

- Species Data Display: Display statistical data for the 10 most representative species of the Galapagos Islands.
- Interactive Visualization: Enable interactive data visualization (charts, graphs) for researchers.
- Role-Based Access: Implement role-based access control (admin, researcher, tourist).
- Data Editing: Allow administrators and researchers to edit and update the displayed statistical data. Tourist do not have permission to login or view protected information.
- Insight generation: Generate simple insights on the displayed data. This will serve as a summarization tool to improve user experience.
- Public information access: Allow tourists to browse public information with no authentication requirement

## Style Guidelines:

- Primary color: Saturated blue (#3498DB), evoking the ocean surrounding the Galapagos.
- Background color: Light gray (#ECF0F1), to ensure readability and a professional look.
- Accent color: Yellow (#F1C40F), analogous to blue, for highlighting key data points and interactive elements.
- Headline font: 'Poppins' sans-serif, to maintain a precise contemporary feel.
- Body font: 'Inter' sans-serif, to maintain a neutral and professional tone.
- Use detailed icons representing each of the 10 most representative Galapagos species.
- Responsive layout adapting to different screen sizes, ensuring accessibility on various devices.
- Subtle transitions and animations when loading or updating data to maintain user engagement.
